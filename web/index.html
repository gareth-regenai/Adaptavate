About this build. Every figure is calculated on the server using the configured workbook, and only the finished values are returned to this page, so the underlying formulas are never exposed to a partner. Until Adaptavate's real model is supplied, the workbook behind these numbers is a stand-in written for development, and the figures are illustrative. Live IoT feeds, ML optimisation and open self-service sign-up are out of scope for Phase 1.
